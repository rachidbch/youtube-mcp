# Changelog

All notable changes will be documented in this file.

## 1.0.1 - 2026-10-13

- `search_youtube` no longer drops options YouTube cannot apply without saying so. `sortBy: "date"` keeps relevance order and `sortBy: "rating"` sorts by popularity, each with a warning; `uploadDate: "hour"` is applied as `today` with a warning. Warnings appear in a new optional `warnings` field and in the text.
- Result caches have a size limit and drop expired entries, so a long-running server no longer keeps every distinct query in memory.
- First release published by the GitHub workflow through npm trusted publishing, with provenance.

## 1.0.0 - 2026-10-13

- First npm and MCP Registry release as `@granitebps/youtube-mcp`, with the `youtube-mcp` executable.
- Errors are classified with stable codes (`ACCESS_BLOCKED`, `VIDEO_UNAVAILABLE`, `PARSE_ERROR`, `TIMEOUT`, and others) and keep YouTube's HTTP status, playability status, and reason. Access blocks are no longer reported as missing videos or missing captions.
- Deadlines and MCP cancellation abort the underlying HTTP requests, including client initialization. The stdio server exits when its client disconnects.
- `get_video_info` returns `durationSeconds` and uses `null` for unknown values.
- `get_video_transcript` paginates with a configurable per-response cap, reports `isAutoGenerated`, decodes caption text fully, and returns the first manual track when `lang` is omitted.
- Added configurable `YT_*` timeouts and transcript size limits.
- Upgraded youtubei.js to 18.1.0 and the MCP SDK to 1.32.1; the production dependency audit is clean.
- Added an offline test suite, CI on Node 22 and 24, tarball install checks on macOS and Windows, and a tag-triggered release workflow.
